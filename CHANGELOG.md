# Changelog

Versions of the seed spec format.

## 0.1

- First draft of the format: definition, detail bar, built versus planned, required parts of a spec, redaction rules and the leak check, versioning, and how specs travel.
- A one-file template and an optional multi-file layout.
- A reading protocol for agents, a paste-in prompt for writing a spec, and a seed list with a machine-readable twin.
